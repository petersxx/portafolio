1. CONCEPTO DE LA PÁGINA
----------------------------------------------------------------
Sitio web de "Main Technologies", una empresa (ficticia/personal)
de desarrollo de software. Funciona como landing page / portafolio
corporativo de una sola página (one-pager) con las siguientes
secciones, en este orden:

  - Inicio (hero): título, bajada, botones "Ver proyectos" y
    "Hablemos", y una pieza visual 3D (disco giratorio) + estrella
    decorativa.
  - Marquee: cinta animada con palabras clave de los servicios
    (Diseño web, Software a medida, E-commerce, etc.).
  - Nosotros: texto de presentación + estadísticas animadas
    (proyectos, años, tecnologías).
  - Servicios: carrusel con 6 tarjetas (Desarrollo web, Software a
    medida, E-commerce, Aplicaciones web, Diseño UI/UX,
    Automatización e integraciones) + listado de stack tecnológico.
    Es una cinta continua (igual en técnica al marquee de palabras
    clave del hero): se desliza sola todo el tiempo, sin flechas,
    sin puntos y sin paradas entre tarjeta y tarjeta. El bucle es
    perfecto porque en realidad hay dos copias idénticas de las 6
    tarjetas una detrás de la otra, y la animación solo recorre el
    ancho de una copia antes de reiniciarse. Se pausa al pasar el
    mouse por encima o al enfocar una tarjeta con el teclado, y no
    se anima si el sistema tiene activado "reducir movimiento".
  - Proyectos: tarjetas con 3 casos reales de clientes (RENOVA
    Constructora, Solar Guaraní, JAKAY'U), cada una enlaza al sitio
    real del cliente.
  - Contacto: formulario (nombre, email, mensaje) que NO envía
    email — arma un mensaje y abre WhatsApp Web/App con el texto
    precargado.
  - Footer: copyright dinámico (año actual) y link a GitHub.

Estética "chromecore": fondo animado tipo cromo líquido (WebGL),
tipografía Unbounded/Space Grotesk/Space Mono, modo claro/oscuro
("ice chrome" / "black chrome") con toggle persistido en
localStorage, y estrellas/destellos decorativos en SVG.

2. STACK TÉCNICO
----------------------------------------------------------------
  - HTML5 semántico, un solo archivo: index.html
  - CSS3 puro con variables, grid y tema claro/oscuro: css/styles.css
  - JavaScript vanilla, SIN framework ni build (no hay
    package.json ni bundler):
      · js/main.js   → menú, tema, contador de stats, scroll-reveal,
                        nav activo, envío del form a WhatsApp
                        (el carrusel de servicios es puro CSS, sin
                        lógica en JS)
      · js/chrome.js → shader WebGL del fondo animado
      · js/disc.js   → disco 3D con three.js (vía CDN/importmap),
                        con foco de luz y rotación ligada al scroll
  - Modelo 3D: assets/models/disco.glb (optimizado con meshopt +
    texturas WebP)
  - three.js se carga por import map directo desde jsdelivr CDN
    (no está en node_modules)
  - Despliegue: Vercel (hay proyecto vinculado, ver .vercel/) y
    también preparado para GitHub Pages (branch main / root)

No hay backend, base de datos ni build step: es un sitio 100%
estático que puede abrirse con cualquier servidor simple. Se
recomienda `python3 -m http.server 8000` porque el disco 3D no
carga si se abre index.html como archivo local (file://) por
restricciones de módulos ES / fetch del .glb.

4. LO QUE FALTA / PENDIENTE
----------------------------------------------------------------
Cosas identificadas revisando el código que probablemente valga
la pena resolver o decidir:

  - Datos de ejemplo/placeholder en "Nosotros": las estadísticas
    (15 proyectos, 3 años, 12 tecnologías) están hardcodeadas en
    js/main.js (STATS) — confirmar que sean los números reales.
  - Sección "Proyectos" tiene solo 3 casos; si hay más trabajos de
    clientes, faltaría cargarlos.
  - El comentario en js/main.js ("Cambiá este email...") quedó
    desactualizado: ya no se envía por email, se envía por
    WhatsApp — conviene limpiar el comentario.
  - No hay meta tags de Open Graph / Twitter Card (og:image,
    og:title, etc.) para que se vea bien al compartir el link en
    redes o WhatsApp.
  - No hay favicon como archivo real: se usa un SVG inline como
    data URI. Podría convenir un favicon.ico/png tradicional para
    mejor compatibilidad.
  - No hay analítica (Google Analytics, Plausible, Vercel
    Analytics, etc.) para medir visitas.
  - No hay política de privacidad ni aviso legal, algo esperable
    en un sitio de empresa con formulario de contacto.
  - El formulario de contacto no valida ni guarda nada del lado
    servidor: si el usuario no tiene WhatsApp o falla el popup,
    no hay fallback (ej. mailto: o servicio de email tipo
    Formspree).
  - No se ve dominio propio configurado todavía (aparece
    desplegado en Vercel con nombre de proyecto "portafolio"); si
    la marca es "Main Technologies", podría convenir un dominio
    acorde.
  - No hay tests, ni linter, ni CI configurado (razonable para un
    sitio estático de este tamaño, pero queda anotado).
  - README.md sigue mencionando GitHub Pages como opción de
    publicación, pero el despliegue real actual parece ser Vercel
    (existe .vercel/project.json) — podría actualizarse el README
    para reflejar el método de deploy vigente.
  - El logo/marca es solo texto ("Main Technologies") con efecto
    "chrome-text"; no hay isotipo/logo gráfico propio más allá de
    la estrella genérica.

5. CÓMO CORRER EL PROYECTO EN LOCAL
----------------------------------------------------------------
  cd portafolio
  python3 -m http.server 8000

  Luego abrir http://localhost:8000 en el navegador.

6. CÓMO PERSONALIZAR (según README.md)
----------------------------------------------------------------
  - Proyectos: editar las tarjetas dentro de la sección
    #proyectos en index.html.
  - Número de WhatsApp: cambiar WHATSAPP_NUMBER al inicio de
    js/main.js (con código de país, sin "+" ni espacios).
  - Estadísticas: ajustar los números en STATS dentro de
    js/main.js.
  - Colores: modificar las variables CSS en :root de
    css/styles.css.

7. REGISTRO DE CAMBIOS
----------------------------------------------------------------
Cada cambio al proyecto se anota acá (el más reciente arriba),
con fecha, qué se hizo y qué archivos se tocaron.

  [2026-09-15] Carrusel de Servicios como cinta continua
    - Se descartó el enfoque anterior (carrusel paginado con
      flechas, puntos y avance cada 5 s) porque lo pedido era un
      "bucle infinito automático": las tarjetas se deslizan solas
      sin parar, sin que haga falta tocar nada.
    - Se eliminaron las flechas, los puntos indicadores y todo el
      JavaScript del carrusel (ya no queda lógica de carrusel en
      js/main.js).
    - Técnica: se duplicó el bloque de las 6 tarjetas dentro del
      HTML (el segundo bloque está marcado aria-hidden e inert,
      así que no lo ven los lectores de pantalla ni se puede
      tabular hasta él). Una animación CSS (@keyframes) desliza
      todo el conjunto y, al llegar a la mitad exacta del ancho
      total, se reinicia — como el ancho de la copia es idéntico
      al original, el reinicio es invisible.
    - Se pausa al pasar el mouse por encima o al enfocar con
      teclado, y se desactiva del todo si el sistema tiene
      "reducir movimiento" activado.
    - Archivos: index.html, css/styles.css, js/main.js,
      DOCUMENTACION.txt

  [2026-09-15] Servicios convertido en carrusel
    - La grilla de 6 tarjetas de "Servicios" ahora es un carrusel
      horizontal con scroll-snap (deslizable con dedo, trackpad o
      flechas del teclado).
    - Controles: botones anterior/siguiente (se deshabilitan en los
      extremos) y puntos indicadores de página, que se recalculan
      según cuántas tarjetas entran en pantalla.
    - Tarjetas visibles: 3 en escritorio, 2 a partir de 860px, y
      85% del ancho a partir de 560px (se asoma la siguiente).
    - Avance automático cada 5 s, en bucle. Se pausa con el mouse
      encima o con foco dentro, se detiene definitivamente cuando
      el usuario lo usa, y no corre si el sistema tiene activado
      "reducir movimiento".
    - Las sombras de las tarjetas se desvanecen suavemente en los
      costados del carrusel (máscara sobre el margen del
      contenedor) en vez de cortarse en línea recta.
    - Se eliminó la clase .skills-grid, que ya no se usa.
    - Archivos: index.html, css/styles.css, js/main.js, README.md,
      DOCUMENTACION.txt
